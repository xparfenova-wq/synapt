# Как править сайт Synapt

Живой сайт: https://synapt.tech
Всё, что лежит в папке `site/`, попадает на домен автоматически: сервер забирает изменения из ветки `main` раз в две минуты.

## Быстрый порядок работы

1. Правим нужный файл
2. `git add -A && git commit -m "что поправили" && git push`
3. Через пару минут открываем страницу и проверяем

## Что где лежит

| Путь | Страница | Кто правит |
|---|---|---|
| `site/index.html` | Главная | напрямую в файле |
| `site/content/` | Фирменный стиль для соцсетей | напрямую в файле |
| `site/privacy/` | Политика обработки данных | напрямую в файле |

## Страницы услуг и кейсов: правим через генератор

Эти страницы собираются из одного описания, поэтому файл в `site/` править бесполезно: следующая сборка его перезапишет.

1. Открываем `builder/specs.json` и правим тексты, цифры, блоки нужной страницы
2. Запускаем сборку:

```bash
python3 builder/publish.py
```

Скрипт соберёт страницы и положит готовый результат в `site/`.

3. Коммитим и пушим, дальше сервер сам

## Как добавить новую страницу услуги или кейса

1. В `builder/specs.json` копируем блок ближайшей по смыслу страницы и меняем: `slug`, заголовок, цифры, секции
2. В `builder/publish.py` добавляем строку в таблицу `PAGES`: слева слаг из спецификации, справа адрес на сайте

```python
PAGES = {
    'ai-desant': 'desant',
    'новый-слаг': 'адрес-на-сайте',
}
```

3. Запускаем `python3 builder/publish.py`, коммитим, пушим
4. Страница открывается по адресу `https://synapt.tech/адрес-на-сайте/`
5. Добавляем ссылку на неё в меню и в блок «Другие услуги» на соседних страницах

## Правила

- Стиль, кегли, палитра и типографика описаны на https://synapt.tech/content
- Внутренние ссылки только относительные: `/checkup/`, `/desant/`
- Ничего не удаляем из `site/` просто так: страница пропадёт с домена в ближайшие две минуты
- Перед пушем открываем файл в браузере и смотрим глазами

## Откат

- Сервер снимает бэкап перед каждой выкладкой, последние десять лежат в `/var/www/_backups/`
- Через git: `git revert <коммит>` и пуш
