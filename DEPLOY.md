# Как править сайт Synapt

Живой сайт: https://synapt.tech
Исходники страниц лежат в папке `site/`.

## Порядок работы

1. Правим нужный файл в `site/` (например `site/checkup/index.html`)
2. Коммитим и пушим в ветку `main`
3. Сервер сам подтягивает изменения раз в две минуты и выкладывает их на synapt.tech

Проверить, что доехало: открыть страницу и обновить с очисткой кэша.

## Структура

| Путь | Страница |
|---|---|
| `site/index.html` | Главная |
| `site/checkup/` | AI-чекап |
| `site/desant/` | AI-десант |
| `site/globaldent/` | Кейс GlobalDent |
| `site/innorto/` | Кейс INNORTO |
| `site/safe/` | Безопасный слой |
| `site/prodazh/` | Кейс отдела продаж |
| `site/content/` | Фирменный стиль для соцсетей |
| `site/privacy/` | Политика обработки данных |

## Правила

- Стиль и типографика описаны на https://synapt.tech/content
- Внутренние ссылки только относительные: `/checkup/`, `/desant/`
- Ничего не удаляем из `site/`: страница пропадёт с домена в ближайшие две минуты
- Перед пушем проверяем страницу локально, открыв файл в браузере

## Откат

Каждый деплой сохраняет предыдущую версию на сервере в `/var/www/_backups/`.
Откатить можно и через git: `git revert <коммит>` и пуш.
