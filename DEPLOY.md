# Как править сайт Synapt

Живой сайт: https://synapt.tech
Всё, что лежит в папке `site/`, попадает на домен автоматически: сервер забирает изменения из ветки `main` раз в две минуты.

## Быстрый порядок работы

1. Правим нужный файл
2. `git add -A && git commit -m "что поправили" && git push`
3. Через пару минут открываем страницу и проверяем

## Все страницы правим напрямую в site/

Генератора больше нет в рабочем контуре: папка `_archive_builder/` лежит только как история, запускать её не нужно и не для чего. Каждая страница – один самодостаточный файл `site/<адрес>/index.html`, правим его и пушим.

## Версии, откат, резервные копии

Три уровня защиты, ничего руками делать не нужно:

1. **GitHub – вся история.** Каждый пуш в `main` – это версия. Откат к любой: в GitHub открыть Commits → нужный коммит → «Browse files» → скачать, или из терминала `git revert <hash>` и пуш. Через две минуты сервер сам выложит откат
2. **Сервер, снимок перед каждой выкладкой.** `deploy.sh` перед заменой файлов копирует текущий сайт в `/var/www/_backups/synapt-landing-ГГГГММДД-ЧЧММ`, хранит последние 40 снимков. Откат без гита: `cp -a /var/www/_backups/synapt-landing-<дата>/. /var/www/synapt-landing/`
3. **Сервер, ежедневный архив.** Крон в 03:20 собирает `/opt/synapt-deploy/_backups/synapt-site-ГГГГММДД.tgz`, хранит 60 дней

Плюс полный клон репо со всей историей на компьютере Ксюши (`business-shared/_drafts/synapt-repo`) – это четвёртая копия.

Никто ничего не «сотрёт навсегда»: удалённый файл остаётся в истории гита и в снимках сервера. Опасно только одно – коммит с пустой или битой страницей уедет на сайт через две минуты, поэтому перед пушем открываем страницу локально.

## Правила

- Стиль, кегли, палитра и типографика описаны на https://synapt.tech/content
- Внутренние ссылки только относительные: `/checkup/`, `/desant/`
- Ничего не удаляем из `site/` просто так: страница пропадёт с домена в ближайшие две минуты
- Перед пушем открываем файл в браузере и смотрим глазами

## Откат

- Сервер снимает бэкап перед каждой выкладкой, последние десять лежат в `/var/www/_backups/`
- Через git: `git revert <коммит>` и пуш
